# Security Policy

## Scope

This repository is an independent educational portfolio containing data science and machine-learning examples. It is not a hosted production prediction service or a provider of financial, credit, or security decisions.

## Private vulnerability reporting

Do not create public issues containing credentials, API tokens, private datasets, personal information, or exploitable security details.

If GitHub offers **Report a vulnerability** in this repository's Security tab, use that option for a private report. Otherwise, contact the repository maintainer privately using the contact information provided in [README.md](README.md).

Include the affected file, dependency, or component; a safe reproduction using non-sensitive data; potential impact; and suggested mitigation if known.

## Data and model safeguards

- Keep secrets and private datasets out of version control.
- Use synthetic, public, or appropriately authorized sample data.
- Check licenses and permitted uses before distributing datasets or trained models.
- Assess data leakage, privacy, bias, and misinterpretation risks before using models beyond demonstrations.
- Treat predictions involving credit, fraud, or sensitive outcomes as educational examples, not automated real-world decisions.
- Validate dependencies and inputs before running code.

## Maintenance expectations

This portfolio is maintained independently and has no guaranteed vulnerability-response SLA or production support commitment. Local model results are not proof of production reliability, compliance, or fairness.
